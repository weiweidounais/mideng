# 模型录入修复与应用生成验收

日期：2026-10-26。项目：密灯企业知识中台。本轮在现有版本上修复模型录入，增加可保存、调试、发布和运行的节点应用。

## 模型录入

问题原因：旧“添加模型”窗口只有模型 ID，API Key、Base URL 被放在独立的连接标签，无法在添加模型时完成所需配置。

修复后同一窗口直接提供 `API Key（api_key）`、`Base URL（base_url）`、`模型 ID（model）`。默认创建独立连接，也可复用已有连接；修改共享地址或凭证需明确允许。模型与连接在同一事务中保存，校验失败不会留下孤立连接或凭证。

浏览器实际填写并保存了一个独立测试模型，确认服务端模型 ID、Base URL 和凭证已配置标记均正确；重新编辑显示实际 URL，Key 为空，留空保存仍保留凭证。接口未返回测试 Key。该临时模型与连接已删除，没有覆盖已有业务配置，也没有调用真实云服务。

接口：`POST /api/models/configure`、`PATCH /api/models/{id}/configure`。支持新旧字段名，保留已绑定 Embedding 的向量空间保护。提供商模块 **22 项测试通过**，含新增的别名、原子回滚、凭证不泄露、共享连接与绑定保护回归。

截图：[同一窗口的三个实际输入字段](01-model-fields.png)。密钥框为密码输入；截图使用非真实测试 Key。

## 应用生成

新增“应用生成”导航与真实服务端接口。管理员、知识库管理人员可维护草稿，使用者只看到已发布应用。支持开始、知识检索、模型生成、条件分支、文本模板、结果输出六类节点，以及知识问答、文案改写、规则分流三种起始模板。

浏览器验收使用“规则分流联调（可删除）”：

1. 从规则分流模板创建应用，保存 5 个节点和 5 条连线。
2. 在画布选中条件节点，将关键词从“报销”改为“采购”，并修改分支节点名称和实际输出模板。
3. 保存到草稿 v2，流程校验通过。
4. 输入“我需要采购办公电脑”，实际返回修改后的采购指引和本次输入，另一分支标为跳过。
5. 输入“你好，想了解其他制度”，实际运行通用分支。
6. 通过真实服务端发布 v2，再保存不同内容的草稿；独立匿名会话运行仍得到已发布的采购指引，未泄露草稿内容。
7. 验证匿名会话无法读取节点定义、不能修改应用、不能调试草稿，且运行记录仅含自己的记录。
8. 将验收应用恢复为已验证内容并发布。应用已保留，名称明确标注“可删除”。
9. 在浏览器切换为免登录使用者，实际运行发布 v4，采购分支返回修改后的指引；使用者界面没有节点编辑器。
10. 验证专注编辑、参数栏切换、节点拖拽、增加节点、连接连线和删除节点及相关连线。临时画布改动丢弃后，重新打开仍是已保存的 5 节点/5 连线。

规则分流的结果由真实条件与模板节点计算，没有使用模拟模型回答。知识检索和 LLM 节点复用现有真实检索及 LangChain 链；实际云账户调用仍需配置凭证。

截图：[应用模板列表](02-application-templates.png)、[可读的专注节点编辑](03-node-editor.png)、[实际分支执行结果](04-branch-run.png)、[使用者运行已发布应用](05-published-user-run.png)、[未保存修改确认](06-unsaved-confirm.png)。

浏览器验收还发现 React 19 下 Ant Design 5 的静态确认弹窗无法渲染。已按 [Ant Design 官方兼容说明](https://5x.ant.design/docs/react/v5-for-19) 加入官方兼容包并在入口导入，重新验证了离开确认、丢弃临时修改和已保存流程重新载入。模型窗口同时限制了表单滚动高度，标题和保存按钮保持可见。

## 自动化与边界

全量后端及流式契约测试 **92 项通过**；其中应用模块 **26 项**。前端 TypeScript 检查与 Vite 生产构建通过。覆盖应用 CRUD、角色与 CSRF、无环图/孤立节点/重复 ID/变量验证、真假分支与合流、发布快照隔离、乐观锁、运行归属、来源清理、共享并发限制、失败恢复、截止时间和上下文预算。

LLM 合同测试使用真实 LangChain 与受控外部 HTTP 响应，验证实际返回的 21 tokens 被持久化，不代表真实供应商账户验证。生产代码不使用测试替身。

知识问答模板默认开启 `requireEvidence`：没有上游知识内容时返回明确的无依据提示并跳过 LLM。通用文案模型默认关闭此选项。模板变量仅替换字符串，不执行代码；第一版不提供任意脚本、HTTP 或循环节点。

用量仅采用供应商返回值，缺失或纯本地步骤保持未知，不以文本长度估算。关闭运行面板不会取消已提交执行，可在运行记录查看结果；运行中状态与刷新入口已提供。
