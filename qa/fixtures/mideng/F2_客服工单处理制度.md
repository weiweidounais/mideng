# 客服工单处理制度（内部）

版本：V1.2
生效日期：2026-08-01
编制人：客服质量管理组
适用主体：峡谷互娱客服中心

## 1. 工单分级

| 级别 | 定义 | 响应时限 |
|------|------|----------|
| P0 | 全服故障、大面积充值失败 | 15 分钟 |
| P1 | 单服异常、支付通道中断 | 30 分钟 |
| P2 | 个别账号异常、一般咨询升级 | 2 小时 |
| P3 | 建议类、非紧急咨询 | 1 个工作日 |

## 2. 处理流程

1. 接单并确认问题分类与级别。
2. 检索知识库相关条款与历史工单。
3. 给出可执行答复或转技术支持。
4. 关闭工单前须填写结论与依据文档编号。

## 3. 禁止事项

- 不得向用户承诺未上线的补偿方案。
- 不得泄露其他玩家隐私信息。
- 不得跳过质检直接批量关闭工单。

## 4. 考核

超时未响应按级别计入当月服务质量分；重复开单率高于 15% 需复盘。
