# 本地原型切换验收

日期：2026-10-28。

当前 5173 开发入口为独立本地原型，无需启动后端。原型 API 在浏览器中执行，未知接口直接拒绝；开发服务器同时阻断 `/api` 请求，没有向真实 API 的代理回退。

- 原型只读快照保留 2 个知识库、2 份已上传文档及 1 个应用的副本；真实原件未移动、覆盖或重建。
- 所有原型修改保存于独立的浏览器存储键；密钥和口令字段不落盘，不使用真实云模型。
- 7 项实际原型 adapter 检查通过，涵盖副本隔离、秘密剔除、文件占位、聊天模拟、应用分流、发布快照、未知路由及无网络回退。
- TypeScript 与独立原型生产构建通过；真实 API 模式仅在临时目录验证编译，没有覆盖原有发布目录。
- 浏览器中修改节点条件、保存并刷新，确认本地修改仍在；随后恢复验收前的条件并只发布到原型副本。
- 实际导出了完整的原型配置副本；上述浏览器流程没有产生 `/api/` 网络请求。
- 切换前后比对业务记录、加密凭证及原件 SHA-256，均未改变；原有发布目录的 20 个文件逐一校验相同。

运行方式见 [README](../../README.md) 的“本地原型调整”。原型副本在“系统设置 → 导出原型副本”导出，后续仅按用户确认的内容同步，不进行自动迁移。
