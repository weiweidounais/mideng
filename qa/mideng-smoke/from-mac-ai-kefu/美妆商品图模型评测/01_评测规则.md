# 美妆品牌商品主图模型评测规则

版本：v0.5 精简版｜2026-10-27｜实测前校准、冻结

## 1. 目标与原则

为淘宝店主的美妆品牌商品主图生成工具，选择一个主用模型和一个备用模型。

核心要求：商品事实正确、关键颜色稳定、小图可辨、合理困难输入可处理、商品参考与风格参考不混淆。

五维分别过线，不做加权平均。事实错误不能被画面好看或其他高分抵消。以下门槛为项目初始标准，正式测试前统一校准并冻结。

## 2. 测试方式

共30条：10条清晰商品图任务、10条对应的困难输入任务、10条商品图＋风格图任务。每条独立生成3次，共90次；保留全部结果，不挑图、不用重试覆盖失败。

每题先固定：商品事实卡、关键颜色区域、展示与裁切规则；风格题另固定输入角色、必须借鉴的2项约束，以及同商品、同需求的最低可接受主图基线。

困难输入仍须保留可辨认的关键事实。资料不清或冲突，先修复题目；输出把应保留的信息变模糊或隐藏，判失败。

## 3. 五维评分与入围门槛

### A. 商品信息真实性：是／否

逐项检查：品牌与商品身份正确；包装结构和数量正确；必检文字正确；新增描述有资料依据；瓶身、包装与文案信息一致。

单次全部为“是”才通过。任何一次经复核确认的事实错误，立即淘汰当前模型配置。

### B. 色号与关键颜色稳定性：1—5分

统一sRGB和测量程序；在预先固定的稳定颜色区域计算色差ΔE00，取最差区域的数值d。排除高光、阴影、透射与镜面反射，不按整张图平均，也不事后挑选更有利的区域。

| 分数 | 判定标准 |
| --- | --- |
| 5 | d≤2 |
| 4 | 2＜d≤4 |
| 3 | 4＜d≤6 |
| 2 | 6＜d≤10 |
| 1 | d＞10，或经证据确认的关键颜色／色号替换 |

单次≥4分通过。模型至少86/90次通过；出现1分，复核后立即淘汰。无法生成或破坏必测区域，计不通过。

本方法仅衡量数字图相对参考的颜色保留，要求商品关键区域保持约定的中性光照。分界须用品牌方认可的样例校准，不等同于实物色差承诺。

### C. 缩略图辨识与裁切适配：1—5分

固定生成300px、150px预览。默认检查完整方图和居中3:4裁切图，作为内部测试条件；按实际用途调整后冻结。

| 检查项 | 通过标准 |
| --- | --- |
| C1，强制 | 裁切后保留≥99.5%的商品可见面积，关键结构未被裁掉 |
| C2 | 商品包围框长边占容器长边55%—85%；特殊构图提前另定 |
| C3 | 300px预览可准确读出指定品牌文字，或认对指定Logo |
| C4，强制 | 150px预览可从4个同品类候选中认对商品；不给正确答案或原图 |
| C5 | 品牌、品名、关键结构未被新增文字、道具或装饰遮挡 |

每项在全部约定预览中通过才记“是”。C1或C4失败直接1分；否则通过5／4／3／2项分别记5／4／3／2分。

单次≥4分通过。模型至少81/90次通过。

### D. 输入素材适应能力：成对是／否

清晰版与困难版使用同一商品、需求和配置，唯一变量为输入质量。输出同时通过A、B、C，才记可用。

10组配对各重复3次，共30组结果。模型必须同时满足：

- 清晰输入至少27/30次可用。
- 困难输入至少24/30次可用。
- “清晰成功、困难失败”最多3/30次；不能用反向偶然成功抵消。

任一不满足即淘汰。不用平均分掩盖困难输入下的退化。

### E. 商品参考与风格参考的区分：是／否＋GSB

先检查：商品身份、包装和颜色来自商品参考；没有串入风格参考的商品信息；完成预先规定的2项风格约束。全部满足才通过角色检查。

整体风格用GSB，与预先认可的“同商品、同需求、最低可接受主图”盲比。角色检查或A／B／C任一失败，直接记B；其余结果按固定的3个风格点，分别判断候选更好G、相当S、较差B：

- G：至少2项更好，没有较差项。
- B：至少2项较差，没有更好项。
- S：其他情况，整体相当或各有取舍；不能把无法判断记为S。

模型须角色检查≥27/30次通过，GSB中G＋S≥24/30次。任何商品、品牌或色号串入，经复核后立即淘汰。没有合格基线时，先补齐，不用任意候选代替最低标准。

## 4. 最终选择与停止条件

全部五维达标，且至少86/90次返回完整可检查图片、至少77/90次同时通过所有适用的单张要求，才可入围。无图、超时、损坏结果计各适用项失败；仅可检查图片用于确认事实错误。

任一维度已不可能达到门槛，就停止当前候选，换其他模型；不追加抽样冲淡失败。没有合格候选时，结论为“当前配置暂无合格模型”。

主用和完整备用使用相同质量底线。入围后优先比较整体可用率，再比较成本与等待时间；备用另验证对主模型失败的补救与切换能力。

## 5. 评分一致性

人工和机器使用同一素材、事实卡、预览、基线与计算结果。数值项由固定程序判档；判断项必须记录具体错误位置或对比证据。

正式测试前，用至少30个独立校准样例验证：每维标签／整数分完全一致率≥90%，通过结论一致率≥95%，关键事实错误、确认的错色号与商品串入漏判为0。统计复核前答案，不能用复核后的统一结论冒充一致性。

未达线，先修正规则或评审方法，不据此淘汰生图模型。正式评分有分歧时复核，二值不取平均，1—5分不取小数。GSB需实测验证一致性，不承诺仅凭文字规则即可100%一致。
