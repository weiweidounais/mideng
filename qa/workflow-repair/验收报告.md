## 原因与修复

1. SenseNova 型号与 Key 被录入为 OpenRouter，实际请求错发至 OpenRouter 官方地址。已改为 SenseNova 官方 token.sensenova.cn/v1；对话、重排和图片理解均真实测试成功。
2. SenseNova Flash 是对话/视觉理解模型，不能直接输出向量。原错误向量配置保留并停用，改为已安装的本地中文向量；SenseNova 重排通过明确的对话评分适配实现，每批最多8个片段并验证评分。
3. sensenova-u1.5-fast 未在服务商实际模型列表中出现，且 U 系列生图能力不能用于 RAG 图片理解。原配置保留并停用，另建 SenseNova 文档图片理解配置并实测成功；本次未实现生图工作流。
4. 用户确认千问配置的 Key 来自 DashVector 控制台；那是向量数据库凭证，不是百炼 / DashScope 模型凭证。已标明原因并停用该错误配置，未删除 Key。要启用千问，需要在百炼创建北京地域模型 Key，更新、启用并测试后，在知识库设置中切换并重建索引。
5. 补齐千问多模态 Embedding 原生协议（每批20条、input.contents、output.embeddings、维度与顺序校验）；协议适配经自动化测试，缺少有效百炼 Key，尚未完成该云模型实测。
6. 模型录入新增 SenseNova 与通用兼容服务，能读取实际模型列表；完整 operation URL 归一化；模型测试自动先测连接；401 文案区分地址/平台/地域匹配问题；错误展示在模型卡片。
7. 在线对话新增明确的回答模型选择并存入会话，实际检索遵循知识库保存设置；本地向量正式接入发布、检索、问答、应用和评测，后端自动启动已安装的本地引擎。
8. 前端更新后旧标签页加载旧懒加载文件会白屏，已为 HTML 加入重新验证缓存策略，并加入错误恢复界面；旧页面请刷新一次。
9. 导入日志按实际执行步骤展示模型，向量调用单独有用量时也正确计量；本地计算不虚构 token 数字。
