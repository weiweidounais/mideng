# Shared backend contracts

This project uses FastAPI, SQLAlchemy Entity records, and LangChain. Keep real APIs separate from tests; no simulation fallback in application services.

- `app.config.config`: data_dir Path, sql_url, qdrant_url/api_key, task_mode local/celery, redis_url, request_timeout, allow_private_providers.
- `app.db.db_session()` context manager yields Session, commits on success. `get_entity(db,kind,id,required=True)` -> Entity or 404; `.payload` dict, `.owner`, `.parent_id`. Reassign payload after edits. `list_entities(db,kind,parent_id=None,owner=None)` -> list Entity. `put_entity(db,kind,data,owner=None,parent_id=None)` -> Entity, data has id; no internal commit.
- Kinds: kb, doc, task, model, connection, chat, log, setting. Data uses frontend camelCase. `setting` id=system. `doc` has originalPath internal, chunks, draftChunks optional, publishedIndexVersion internal. `kb` embedding is modelId string, embeddingConfigId preferred binding ID.
- `app.security.current_session(Request)` dependency -> Actor(owner:str,role:str,csrf:str); `require_manager` / `require_admin` dependencies. Every modifying endpoint requires valid CSRF checked by middleware; safe authenticated GET allowed. Worker imports services directly, no actor needed.
- `app.providers.get_model(db, type, model_id=None)` -> dict valid enabled tested model + connection must be usable; `get_connection(db,model)` -> connection dict; `credentials(connection_id)` -> decrypted dict; `make_chat(db,model, streaming=True)` LangChain ChatOpenAI; `make_embeddings(db,model)` LangChain Embeddings; `rerank(db,model,query,documents,top_n)` -> (list {index,score},usage dict). Provider adapter owner defines exact final signatures and tells others.
- Ingestion owner: `app.ingestion.router` mounted `/api`; `recover_jobs()` called lifespan; `shutdown_jobs()`; `enqueue(task_id)` schedules persistent task for local worker or Celery; `app.ingestion.process_task(task_id)` sync durable pipeline; retrieval owner implements vector API used by ingestion (coordinate directly).
- Retrieval owner: `app.rag.router` mounted `/api`; `get_vector_store()` Qdrant client; implement `index_document` + `remove_document_vectors` API and communicate exact signatures to ingestion owner. Provide LangChain retrieval+prompt+stream chain. Chat POST stream `/chat/stream` data {sessionId?,kbIds,question,regenerate?}; SSE event types meta, sources, token, done, error. Meta has sessionId,assistantId,requestId. Sources type frontend fields with optional chunkId/version/assetUrl. Done {session,message,log}. Abort recorded cancelled. Sessions owner-scoped for anonymous and manager alike; do not trust browser-supplied role/owner.
- Errors: FastAPI HTTPException sanitized message no secret values. Logging usage real numbers or null, never pretend 0 for missing. Store time full ISO and display time Asia/Shanghai string in `time` / updatedAt.
- Frontend root will migrate all pages to explicit API mutations; do not create blanket client-controlled database snapshot writes.
