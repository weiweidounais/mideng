# 密灯 · 企业内部 AI 客服产品说明

> 【测试虚构】产品能力与套餐名为评测语料，非真实报价。

## 产品定位

「密灯」面向企业内部知识中台，将制度、FAQ、表格与长文导入后，为员工与一线客服提供**有据问答**。答案附带来源片段，便于质检与追责。

## 核心能力

1. **知识导入**：支持 md / pdf / docx / xlsx / csv；可配置切块策略。  
2. **混合检索**：向量 + 关键词，可选重排。  
3. **场景应用**：售后 FAQ、制度问答、产品参数查询。  
4. **可观测**：请求日志、耗时、来源命中。

## 部署形态（虚构）

| 形态 | 说明 |
| --- | --- |
| 本地原型 | 浏览器副本，不调云模型 |
| 内网单机 | SQLite + 本地向量 |
| 企业部署 | PostgreSQL + Qdrant |

## 与「小峡」素材的关系

游戏客服题材（信誉分、充值退款）可作为另一知识库并行导入；本说明侧重**通用企业售后**场景，便于对比切块效果。
