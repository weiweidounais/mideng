# 质保与寄修政策（摘要）

> 【测试虚构】与退换货制度配套的维修侧口径。

## 质保范围

整机质保 **12 个月**，电池等耗材质保 **6 个月**。保修凭证为电子保卡（订单号即可查询）。

## 非保情形

进液、摔裂、私拆、烧机超频、未授权改装。非保可付费维修，报价在建单后 1 个工作日内给出。

## 寄修流程

1. 密灯客服创建维修单，获得单号与寄修地址。  
2. 自行包装寄出，建议保价。  
3. 中心签收后检测，短信通知方案（修 / 换板 / 无法修）。  
4. 用户确认后开工；完成后原址寄回。

## 时限

标准寄修 **5～10 个工作日**（不含物流）。缺配件时最长顺延 10 日并通知用户。
