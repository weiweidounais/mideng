# 使用与核对

1. 在这台Mac打开 http://127.0.0.1:18430/，使用原账号登录，密码沿用用户统一设置。
2. 打开原项目，确认“交接与采购、变更与处置、管段与质量、成本与月结”仍可按原岗位使用。
3. 进入“项目知识与应用”。项目经理、设计、商务或项目管理员可建立知识空间；默认仅资料责任人和指定成员可读。
4. 使用合成或脱敏文件上传，等待解析后点“核对片段”；核对无误再发布。指定成员可查找原文、下载来源；草稿对其他成员不可见。
5. 在“规则应用”建立模板，可编辑流程节点和连线，先试运行，再填写发布前测试输入及预期文字。测试不通过时不发布；已发布内容与新草稿独立，历史发布可以回退。

正常项目没有混入验收用的合成合同、成本或知识资料。以上创建与发布操作会保存到当前项目，应由有权本人确认；本轮Agent仅在隔离验收库做了这些操作。

原18410作为旧版保留，数据与18430独立。日常使用请选择新18430入口。
