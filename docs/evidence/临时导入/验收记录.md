# 浏览器内临时导入验收 · 2026-11-06

已发布并实测：https://weiweidounais.github.io/mideng/#/overview 。入口位于探索知识标题下方“临时导入资料”。

## 行为与边界

支持 TXT、MD、CSV 原文检索，不解析 Office、PDF、图片或 OCR，不调用 AI。UTF-8 和带 BOM 的 UTF-16 可读取；未知编码提示另存 UTF-8。每份最多1MB、最多10份、合计5MB。原文件只在访客浏览器当前页面内存中持有，不上传服务器，不写 localStorage、sessionStorage 或 IndexedDB。

导入后标记“临时导入 · 仅当前页面”，支持全文关键词检索、摘要、展开预览、按原文件名下载完整原件、单份移除与全部清空。切换导航保留，刷新或重置清空；异步读取通过序号隔离，重置前的读取结果不会回写。

文本以 React 普通文字显示，不解释 HTML/Markdown 标签、脚本或 CSV 公式。卡片摘要最多320字符，展开预览最多10000字符，全文检索和原件下载保留完整文本及文件字节。PDF/ZIP等伪装文件、无效控制字符、空白、超限及同名同字节重复文件拒绝导入；同名不同内容或不同来源文件名保留为不同资料。

七个导航入口继续保留。静态产物不含访客文件，企业后台与原本机业务服务未改动。浏览器测试仅使用合成夹具。
