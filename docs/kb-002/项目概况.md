## 第一批用户（五角色）
市场、商务、项目经理、设计、采购

## 一期产品范围（做）
1. 甲方需求入口（市场 → 商务）
2. 对内同步：商务 → 设计 / 采购 / 项目经理（同版本、变更留痕）
3. 方案优化输出（设计回写）
4. 设计↔采购 接口契约台账（主契约：BOM/料表交接）
5. 例外 / 待办一页纸
6. 采购侧料表/交期状态（演示可不对接用友）

## 一期明确不做
- 变更全链路 SLA、管段追溯、成本账 T+3（可占位）
- 合同审查 AI、算量 AI、大而全双驾驶舱
- 强制用友双向同步 / CRM 全量替换 / 完整投标报价引擎

## 信息流（演示链）
```text
甲方需求（市场录入）
  → 商务交底包（确认并发布）
  → 设计 / 采购 / 项目经理同步可见（同版本）
  → 设计回写方案优化要点
  → 商务/市场用于对甲方沟通
  → 设计↔采购 BOM 契约推进
  → 项目经理例外页能看到断点
```
