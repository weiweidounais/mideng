## 观点（非事实）

1. **最伤检索质量的缺口**是 B3/B4 + C2–C8：切块与元数据仍停留在「字符切 + 全文向量」，UI 文案已超前于实现。  
2. **最伤产品叙事的缺口**是 A5–A7：应用画布已有，但报告/生成/审核没有场景模板，客户会以为「应用生成」已覆盖业务场景。  
3. **最伤工程效率的缺口**是 F2/F12：demand 独立页与 CollaborationPage 双轨，后续改原型极易改错文件。  
4. 可观测应先把 **import / chat / retrieval / application_run** 收到同一 Trace 模型，再谈 Agent/Skill（当前产品内尚无 Agent 运行时）。
