# 密灯公开演示

访问：https://weiweidounais.github.io/mideng/

本演示用于公开展示产品协作路径，不是企业业务环境。所有项目、合同、供应方、材料和金额均为人工合成；不提供真实账号登录、文件上传、数据库或模型连接。角色切换只演示不同岗位的责任，不是身份认证。所有操作在当前页面内存运行，刷新或“重置演示”后恢复初始状态。

## 体验路径

- 采购：设计确认方案 → 项目经理提出采购需求 → 采购接单并登记下单 → 项目经理复核数量及约定到货 → 采购登记实际到货 → 质量验收 → 商务归档。每一步可点击提示切换对应演示角色。
- 变更：分别核对技术、成本、进度、质量影响，登记合成批准、送达和对象处置，关闭前拦截旧依据继续执行。
- 管段：材料、焊缝、预制、检测、发运、安装、试压和质量确认。
- 成本：错误合成源表整批拦截，切换财务并使用完整样例后模拟入账，明确勾选核对后发布合成月结。
- 知识：关键词匹配两份合成原文，可下载合成 Markdown；不是模型问答。
- 规则：编辑节点后先保存流程草稿，再试运行与发布快照；发布版本与后续草稿分开。本地模板计算不调用模型、不执行实际采购或审批。

## 构建与发布

```sh
cd frontend
npm ci
npm run test:demo
npm run build:demo
npm run preview:demo
```

预览地址为 `http://127.0.0.1:18432/mideng/`，独立输出 `frontend/dist-demo/`，不会覆盖本机业务前端。GitHub Pages 使用 `/mideng/` 资源前缀和 hash 路由。只将构建目录内容提交到 `gh-pages` 分支根目录，保留 `.nojekyll`；源码留在整合分支，不合并或覆盖原版 main。

构建后检查静态文件类型与本机运行地址引用，使用 `connect-src 'none'` 禁止页面发起后端、模型或 WebSocket 连接。静态资源只从当前站点加载，不包含账号会话、运行库、企业原件、环境配置或私钥。公网访问的页面和合成交互与本机 18410 / 18430 业务服务隔离。

重新发布前运行前端回归、演示测试、类型检查、Lint、构建、凭据检查和静态产物扫描。发布后核对 Pages 状态、HTTPS 首页与资源、外网交互与手机导航。测试证据见 `docs/evidence/公开演示/`。

完整业务系统如需对外使用，需另行确定后端部署域、身份授权和业务数据范围；本次未将企业系统发布到公网。
